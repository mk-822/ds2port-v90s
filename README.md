# DS2Port V90S

所有する **Compile DiscStationのWindowsゲームを、PlumOS V90S V2で遊ぶためのWindows用転送ツール**です。PCでゲームのフォルダーを選び、本体へ転送するとPortsから起動できます。

**[Windows版をダウンロード（v0.1.2・プレリリース）](https://github.com/mk-822/ds2port-v90s/releases/tag/v0.1.2)**

| PCの転送ツール | V90Sでの動作例（FLOAT） |
| --- | --- |
| ![ゲームと接続先を指定する転送ツール](docs/images/transfer-tool.jpg) | ![V90Sでフロートランドのおとぎばなしを起動した実機写真](docs/images/float-on-v90s.png) |

## できること

- ゲームのフォルダーとEXEを選んで転送。タイトルの事前登録は不要です。
- 日本語表示のずれを補正し、FM音源でのBGM再生と効果音に対応します。
- 本体のボタンでマウス操作と4ボタンJoypad操作を切り替えられます。
- 本体の音量ボタンや電源メニューを利用できます。
- 複数のゲームで共通データを共有し、本体の空き容量と再転送の量を節約します。

## 使い方

必要なもの：Windows x64のPC、PlumOS V90S V2の本体、所有するDiscStationの32bit Windowsゲーム。

1. ダウンロードしたZIPを展開し、`DS2PortV90S.exe` を起動します。ZIP内のファイルはまとめて同じフォルダーに置いてください。
2. 本体のWi-FiとSSHを有効にします。起動中のゲームは終了してください。
3. ツールでゲームのフォルダーと起動EXE、起動時の操作モードを選び、本体のIPアドレスとSSHログイン情報を入力します。EXEが1つなら自動で選ばれます。
4. 「接続を確認」で空き容量を確認し、「ゲームを転送」を押します。初回のみ接続先のSSHホスト鍵を確認して登録します。
5. 本体の **Ports** からゲームを起動します。初回起動には数分かかる場合があります。

更新するときは、ゲームを終了して新版ツールで同じゲームを再転送してください。PC側の原本は変更せず、本体の既存セーブを保持するように転送します。

## 操作

**L2**でマウス／Joypadモードを切り替えます。起動時のモードは転送ツールで指定できます。

| 操作 | マウスモード | Joypadモード |
| --- | --- | --- |
| 十字キー | カーソル移動 | 方向入力 |
| B | 左クリック | ボタン2 |
| A | 右クリック | ボタン3 |
| Y | 押している間カーソル2倍速 | ボタン1 |
| X | 割り当てなし | ボタン4 |
| R2 | 押している間カーソル2倍速 | 割り当てなし |

両モード共通で **START＝Enter、SELECT＝Escape、START＋SELECT＝ゲーム終了**。L1/R1は割り当てなしです。モードを切り替えたときは左上に約2秒間表示します。

## 動作確認と補足

JUMP3・FLOAT・OPMON・DF3・GEO3・ANGLERで表示や操作を確認しています。すべてのタイトルや場面を保証する段階ではないため、プレリリースとして公開しています。[詳しい検証記録](docs/VALIDATION.md)

ゲーム本体とMSゴシックは配布物に含みません。ゲームは利用者が用意し、MSゴシックは転送ツールを実行するPCから取得します。本体にはゲーム用と動作環境用の空き容量が必要です。
