# 動作確認

対象：PlumOS V90S V2、AArch64、Linux 4.9.191、640×480。

既存の手動構築環境では、以下を順に確認しています。

1. Box64でLinux x86-64プログラムを実行。
2. Wine WoW64でWin32コンソールとGDIウィンドウを表示。
3. DirectDraw 640×480・8bitのサーフェス・パレット・Blt成功。
4. JUMP3のタイトル・本編会話・画面・操作を実機で確認。
5. MSゴシックで会話4行、Aで左クリック、OPL3の音源をユーザーが確認。
6. MIDI受信枠2000、イベント欠落0。サステイン中のAll Notes Off・All Sound Off・GMリセットで波形が無音になる自己検査に成功。

転送ツールの検証（2026-10-23）：

- 公開用DockerfileからARM64ランタイムをビルド。Box64のライセンスとWine用Xcursorライブラリを同梱。
- OPL3音声生成と、サステイン中のAll Notes Off・All Sound Off・GMリセットの消音検査に成功。
- Windows GUI・CLIのEXEを生成し、GUIの初期化・リソース読込・レイアウト検査に成功。
- 生成したCLI EXEから実機へSSH接続し、CPU・空き容量・読み取り専用状態を取得。
- 12件の単体検査に成功。所有ゲームからのパッチ生成・原本保持、ランタイムに私有ファイルがないこと、アーカイブのパス・リンク・重複拒否、日本語設定で無関係なレジストリ値を保持する検査を含む。
- CLI EXEによる新規転送と本体上の `BOX64_LINUX_OK` を確認。
- 空のWine prefixから初期化し、ゲームのタイトル表示まで確認。初回環境作成は本体で数分必要。
- マウス押下・解放がゲーム内部の状態へ届き、「はじめから」で本編の導入へ進むことを確認。
- 会話用フォント寸法22×16、マウスフック登録成功、MIDI受信枠2000・ピーク1040・欠落0を確認。
- 最終CLI EXEで既存テスト環境を更新し、再起動に成功。転送元のSaveData内の同名ファイルを別内容へ変更しても、本体の既存内容が保持されることを確認。
- 日本語ロケールを指定したWin32検査で `WINDOWS_ACP=932 SYSTEM_LCID=1041 USER_LCID=1041` を確認。
- 最終EXEのGUI初期化と12件の単体検査を再確認。検証専用環境のセーブをPCの非公開領域へ退避後、その環境だけを削除。既存JUMP3環境を保持し、本体のext4空き容量2.3GBを確認。

生成ログはGit対象外の `bld/` に保存します。ゲーム本体・画面画像・資格情報は公開テストfixtureへ含めません。

未検証範囲：他タイトル、全ミニゲーム、クリアまでの長時間プレイ、すべてのセーブ／ロード操作。
