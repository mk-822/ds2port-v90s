# DS2Port V90S v0.1.1（プレリリース）

所有するCompile DiscStationのWindowsゲームを、Windows PCから **PlumOS V90S V2** へ転送して遊ぶためのツールです。

## 今回よくなったこと

- **DF3などを転送できるように。** 「マウス互換修正用の空き領域がありません」と表示され、転送が止まる問題を修正しました。
- **DF3の文字や数値を読みやすく。** 名前入力の「けってい」が枠に収まり、ボーナスポイントなどの数値が表示されるようになりました。

JUMP3の会話表示と、FLOATの文字幅も実機で確認しています。

## 使い始めるには

1. 添付の `ds2port-v90s-0.1.1-windows-x64.zip` を展開し、`DS2PortV90S.exe` を起動します。
2. 本体のWi-FiとSSHを有効にし、ゲームのフォルダー・EXEと接続先を指定して転送します。
3. 本体のPortsからゲームを起動します。初回起動には数分かかる場合があります。

詳しい使い方・操作方法とスクリーンショットは **[README](https://github.com/mk-822/ds2port-v90s#readme)** をご覧ください。

ゲーム本体とMSゴシックは同梱していません。ゲームは利用者が用意し、MSゴシックは実行PCから取得します。まだ検証中のプレリリースです。[この版の検証記録](https://github.com/mk-822/ds2port-v90s/blob/v0.1.1/docs/VALIDATION.md)
