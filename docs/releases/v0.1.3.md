# DS2Port V90S v0.1.3（プレリリース）

所有するCompile DiscStationのWindowsゲームを、Windows PCから **PlumOS V90S V2** へ転送して遊ぶためのツールです。

## 改善点

- **接続先を毎回入力する手間を削減。** 本体のIPアドレスとSSHユーザーを終了時に保存し、次回起動時に復元します。
- **パスワードの保存を選択可能に。** 「SSHパスワードを保存する」にチェックすると、終了時にこのPCへ保存します。チェックを外して終了すると、以前保存したパスワードも削除します。
- **説明を簡潔に整理。** READMEを機能・使用方法・操作方法を中心にまとめ、リリース説明も改善点が伝わる内容へ変更しました。

接続情報の保存はPC側ツールの更新だけで利用できます。

## 使用方法

1. 添付の `ds2port-v90s-0.1.3-windows-x64.zip` を展開し、`DS2PortV90S.exe` を起動します。
2. 本体のWi-FiとSSHを有効にし、ゲームのフォルダー・EXEと接続先を指定して転送します。パスワードも保存したい場合はチェックを付けます。
3. 本体のPortsからゲームを起動します。初回起動には数分かかる場合があります。

詳しい使用方法・操作方法とスクリーンショットは **[README](https://github.com/mk-822/ds2port-v90s#readme)** をご覧ください。

ゲーム本体とMSゴシックは同梱していません。ゲームは利用者が用意し、MSゴシックは実行PCから取得します。まだ検証中のプレリリースです。
