# DS2Port V90S v0.1.0（プレリリース）

所有するCompile DiscStationのWindowsゲームを、Windows PCから **PlumOS V90S V2** へ転送して遊ぶためのツールです。

## 最初のプレリリース

- 所有するDiscStationのWindowsゲームを、本体へ転送してPortsから起動できます。
- 日本語表示、FM音源のBGM、効果音に対応します。
- L2でマウス／Joypad操作を切り替えられ、本体の音量ボタンと電源メニューも利用できます。

JUMP3・FLOAT・OPMONの表示・操作・音と、JUMP3のJoypad専用ミニゲームを実機で確認しています。

## 使い始めるには

1. 添付の `ds2port-v90s-0.1.0-windows-x64.zip` を展開し、`DS2PortV90S.exe` を起動します。
2. 本体のWi-FiとSSHを有効にし、ゲームのフォルダー・EXEと接続先を指定して転送します。
3. 本体のPortsからゲームを起動します。初回起動には数分かかる場合があります。

詳しい使い方・操作方法とスクリーンショットは **[README](https://github.com/mk-822/ds2port-v90s#readme)** をご覧ください。

ゲーム本体とMSゴシックは同梱していません。ゲームは利用者が用意し、MSゴシックは実行PCから取得します。まだ検証中のプレリリースです。[この版の検証記録](https://github.com/mk-822/ds2port-v90s/blob/v0.1.0/docs/VALIDATION.md)
