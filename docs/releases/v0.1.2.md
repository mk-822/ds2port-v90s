# DS2Port V90S v0.1.2（プレリリース）

所有するCompile DiscStationのWindowsゲームを、Windows PCから **PlumOS V90S V2** へ転送して遊ぶためのツールです。

## 改善点

- **本体の空き容量を節約。** ゲームごとに重複していた動作環境をまとめて保存します。4タイトルで約1.8GB分を削減できました。
- **2本目以降や更新時の転送量を削減。** 本体にある共通データの再転送を省きます。
- **会話やメニューの文字を読みやすく。** ANGLERなどで文字が枠からはみ出したり、狭い文字幅が正しく反映されなかったりする問題を改善しました。
- **BGMを聞き取りやすい音量バランスに。** BGMの音量を保ち、効果音などを従来の約7割に調整しました。

JUMP3・DF3の文字表示も実機で再確認しています。

## 使用方法

1. 添付の `ds2port-v90s-0.1.2-windows-x64.zip` を展開し、`DS2PortV90S.exe` を起動します。
2. 本体のWi-FiとSSHを有効にし、ゲームのフォルダー・EXEと接続先を指定して転送します。
3. 本体のPortsからゲームを起動します。初回起動には数分かかる場合があります。

詳しい使い方・操作方法とスクリーンショットは **[README](https://github.com/mk-822/ds2port-v90s#readme)** をご覧ください。

ゲーム本体とMSゴシックは同梱していません。ゲームは利用者が用意し、MSゴシックは実行PCから取得します。まだ検証中のプレリリースです。[この版の検証記録](https://github.com/mk-822/ds2port-v90s/blob/v0.1.2/docs/VALIDATION.md)
